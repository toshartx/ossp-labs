# Лабораторная работа №4: Взаимодействие процессов (Вариант 23)

## 1. Номер варианта и задание
**Вариант 23. Общий счетчик.**
**Механизмы:** Shared Memory (разделяемая память), Mutex, InterlockedIncrement.
**Задача:** Три рабочих процесса увеличивают общий счетчик по 50 000 раз каждый. 
Необходимо реализовать два режима синхронизации:
1. Изменение счетчика под защитой `Mutex`.
2. Изменение атомарной операцией `InterlockedIncrement`.

Требуется проверить итоговое значение счетчика и сравнить производительность при 2 и 3 процессах.

## 2. Краткое описание программы
Программа состоит из двух исполняемых файлов:
*   **Manager** (главный процесс): создает объект разделяемой памяти (`CreateFileMapping`) и именованный мьютекс. Запускает заданное количество дочерних процессов-воркеров. По завершении всех воркеров проверяет инвариант (итоговое значение счетчика) и выводит время выполнения.
*   **Worker** (дочерний процесс): подключается к разделяемой памяти (`OpenFileMapping`) и мьютексу. Выполняет заданное количество инкрементов общего счетчика, после чего завершается.

Для предотвращения гонки данных используются два режима: блокировка мьютексом и атомарная операция `InterlockedIncrement`.
Ведется потокобезопасный журнал состояний (START, FINISHED) в файл `log.txt`.

## 3. Требования к среде выполнения
*   Операционная система: Windows 10/11.
*   Компилятор: MSVC (Visual Studio 2022).
*   Стандарт C++: C++17 или выше.
*   Сторонние библиотеки: не требуются.

## 4. Инструкции по сборке
Проект состоит из двух подпроектов в одном Solution (Решение).
1. Откройте файл `ossp-labs.sln` в Visual Studio 2022.
2. Выберите конфигурацию `x64` (Debug или Release).
3. Соберите решение (Build Solution / Ctrl+Shift+B).
4. **Важно:** скопируйте исполняемый файл `Worker.exe` в директорию, где находится `Manager.exe` (обычно `x64/Debug/`), чтобы менеджер мог найти воркера при запуске через `CreateProcess`.

## 5. Параметры запуска
Программа параметризована (п. 4.1 требований). Параметры передаются через аргументы командной строки при запуске `Manager.exe`:

`Manager.exe [число_воркеров] [операций_на_воркера] [режим_синхронизации]`

*   `число_воркеров` — целое число (по умолчанию 3).
*   `операций_на_воркера` — целое число (по умолчанию 50000).
*   `режим_синхронизации` — `1` (Mutex) или `2` (InterlockedIncrement). По умолчанию `1`.

*   Запуск с параметрами по умолчанию:
